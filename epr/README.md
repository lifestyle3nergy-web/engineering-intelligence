# Engineering Problem Records

Individual EPRs live here, one file per record, named `EPR-NNN-short-slug.md`.

The atlas in `wiki.md` is the index. This directory is the long form. When an EPR grows past what a section in the atlas can hold, it moves here and the atlas keeps a one-line summary with a link.

Every EPR follows this structure:

- **Number and title**
- **Constraint** — what the problem is, in one paragraph
- **Historical evidence** — what actually happened, labelled by evidence class
- **Engineering inference** — what the evidence suggests, labelled as inference
- **Transfer to TWGT** — the specific governance, schema, or implementation action this EPR motivates
- **Sources** — ordered by the hierarchy in `wiki.md` §2
- **Completion criteria** — what would let this EPR be marked closed

No EPR is closed without a transfer action. An EPR that names a problem and stops is a complaint, not a record.
